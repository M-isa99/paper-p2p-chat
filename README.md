# PaperChat P2P

A real-time peer-to-peer chat application built with a paper-like A4 notebook aesthetic, featuring highlighters, sticky notes, custom usernames, Yjs CRDT synchronization, IndexedDB persistence, PeerJS data channels, and real-time WebRTC voice chat.

## Features
- **Paper Aesthetics**: A4 notebook styling with red margin lines, Google Fonts (`Kalam` & `Special Elite`), and highlighter/sticky-note formatting.
- **PeerJS & Yjs**: Decentralized P2P connection backed by Yjs CRDTs for robust message propagation.
- **IndexedDB Persistence**: Automatically caches chat history locally in the browser.
- **Real-Time Voice Chat**: Automatic microphone streaming between connected peers.
- **Typing Indicators**: Live typing notifications.
